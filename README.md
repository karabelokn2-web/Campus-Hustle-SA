# Campus Hustle SA 🎓

**Gauteng’s Student Gig Marketplace**

Campus Hustle SA is a modern, mobile-friendly web application that helps students in Gauteng earn extra income by offering their skills and finding flexible gigs.

---

## ✨ Features

- **User Authentication**
  - Login / Sign Up
  - Role selection (Student Looking for Work or Gig Poster)
  - Institution selection (UJ, UP, Wits, TUT, VUT, UNISA, etc.)

- **Dashboard**
  - Overview of Active Gigs, Applications, Messages, Earnings, and Network

- **Explore Gigs**
  - Search functionality
  - Filter by Category (Tutoring, Coding, Graphic Design, Photography, etc.)
  - Filter by Location (Johannesburg, Pretoria, Soweto, Midrand, Centurion, etc.)

- **Post a Gig**
  - Easy form to create new opportunities

- **Apply / Contact**
  - Students can apply to gigs with one click

- **Notifications**
  - Interactive notifications with read/unread status

- **Profile**
  - Personal information
  - **EFT Banking Details** (for receiving payments)
  - Legal documents (Terms of Service, Privacy Policy, Payment Terms, Community Guidelines)
  - **My Applications & Receipts**
    - Mark gigs as paid
    - Generate professional payment receipts

- Fully responsive (Desktop, Tablet & Mobile)

---

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- LocalStorage (for demo data & session)

---

## 🚀 How to Run Locally

1. Download or clone this repository
2. Open the `index.html` file in any modern browser
3. That’s it — no installation required
